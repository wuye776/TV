【四、v1 架构（相对其他站的差异点）】
────────────────────────────────────────────────

  ✓ 数据主通道 = 站方 MacCMS v10 JSON API（/api.php/provide/vod/）：
    ac=list 翻页 + ac=detail&ids=批量20 取封面/详情，两请求一页，带 LRU 缓存
  ✓ 兜底通道 = 网页爬取 /t/<id>-<pg>/：分类 1/2/3/5 站方 API 屏蔽（t=2 total=0），
    走 HTML 卡片解析，标题从封面 URL 的 b64 段解码（站方反爬把标题藏进封面图 URL）
  ✓ 域名自愈：门域 mm.9999999993.cc 所有路径 301 → 289xx.cc；spider 探活失败或
    遇 301 自动改写 HOST；init({base:新域}) 可注入新门域
  ✓ 取流：m3u8 在 imgcdn.u8-*.xyz/sd/<md5>.m3u8，分片在 xhscdn（无 Referer/UA 防护），
    KEY 同域 200，AES-128 播放器原生解
  ✓ 封面 = aaa.img-*.xyz/text/<md5>.txt 实为 JPEG 字节（content-type 骗人的 text/plain），
    Glide 按魔数识别，直传即可，无需包装
  ✓ 搜索：API wd= 全站 75816 部，pg 翻页支持；屏蔽类（1/2/3/5）搜不到属站方限制
